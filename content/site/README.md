# Dati del sito

Questi file controllano i contenuti strutturati delle pagine:

| File | Contenuto |
|---|---|
| [`profile.ts`](./profile.ts) | nome, ruolo, descrizione, contatti, social e navigazione |
| [`skills.ts`](./skills.ts) | competenze, livelli, strumenti e descrizioni bilingui |
| [`cv.json`](./cv.json) | esperienze, formazione e sezioni del CV |
| [`certificate-assets.ts`](./certificate-assets.ts) | elenco delle certificazioni e collegamenti ai documenti |
| [`certifications.ts`](./certifications.ts) | riconoscimento degli enti, loghi e colori |
| [`legal.ts`](./legal.ts) | privacy, cookie e termini in italiano e inglese |

I PDF delle certificazioni sono conservati in [`public/certificati/`](../../public/certificati/) e i loghi in [`public/logos/`](../../public/logos/).
