# Progetti

- [`it/`](./it/) contiene le schede progetto italiane.
- [`en/`](./en/) contiene le rispettive versioni inglesi.
- [`_template.md.txt`](./_template.md.txt) è il modello per creare un progetto.

Per aggiungere un progetto, copia il modello nelle due cartelle lingua usando lo stesso nome file. `featured: true` mostra il progetto tra quelli principali; `order` ne controlla l'ordine; `draft: true` lo mantiene nascosto.

Le categorie ammesse sono `security`, `ai`, `automation`, `cloud` e `tool`.
